Privacy Policy

Last updated: October 16, 2026

ClippedAI is a personal tool used by its owner to upload short video clips to the owner's own YouTube channel (and, in future, the owner's own TikTok account).

What data the app accesses

  • YouTube: the app requests only the youtube.upload permission, used solely to upload videos to the owner's channel. It does not read, modify or delete other videos, comments, subscribers, analytics or any other YouTube data.
  • Account information: none beyond the access token needed to upload.
  • Other people: the app does not collect personal data about viewers or any other users.

How data is stored

The access token is stored only on the owner's own computer, with file permissions limited to the owner's user account. No data is stored on any server operated by ClippedAI.

Sharing

No data is sold, shared with or transferred to third parties.

Google API Services User Data Policy

ClippedAI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
